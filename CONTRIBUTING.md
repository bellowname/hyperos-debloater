# Как помочь

1. **Проверь пакеты на своей прошивке.**
   `su -c 'sh /data/adb/modules/hyperos_debloater/scripts/scan.sh'`
   и приложи отчёт к issue — так мы узнаем имена пакетов для других регионов.

2. **Предлагай только безопасные пакеты.** Опиши, что делает пакет и почему его можно
   отключить. Сомнительные кандидаты идут только в `aggressive`.

3. **Перед PR** запусти:
   ```sh
   sh -n module/*.sh module/scripts/*.sh scripts/*.sh
   sh scripts/build.sh
   ```
   Изменения в профилях должны сохранять обратную совместимость: пользователь с
   активным профилем `safe` не должен получить неожиданные отключения.

4. **Формат коммитов:** `profiles: add EEA browser`, `scripts: fix restore`, etc.

5. Не добавляй сетевые запросы и телеметрию. Модуль должен работать офлайн.
